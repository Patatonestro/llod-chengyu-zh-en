# llod-chengyu-zh-en
Chengyu Dataset: A Unique Linguistic Resource

Chengyu (成语) are fixed idiomatic expressions in Chinese, often consisting of four characters. Originating from ancient myths, fables, historical events, and literary works, they encapsulate profound meanings and remain widely used today. Despite their historical and cultural significance, there is currently no Linked Open Data (LLOD) resource dedicated to Chengyu. By integrating Chengyu into the LLOD framework, we provide a structured, open-access resource for language technology and semantic web applications,and supports cultural studies by offering insights into Chinese linguistic heritage.

Our dataset consists of 2,644 entries, collected from open-source dictionaries and cleaned for accuracy. It follows the OntoLex-Lemon model, ensuring structured representation in RDF format. This enables efficient querying via SPARQL and facilitates cross-linguistic comparisons with idioms in other languages(in the current version, only English).
